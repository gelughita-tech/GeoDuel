# Contribuții la GeoDuel

Mulțumim că vrei să contribui la GeoDuel! 🎉

## Cum poți contribui

- 🧠 Adaugă întrebări noi în `data/intrebari.json`
- 🌍 Propune hărți suplimentare în format GeoJSON
- 🎨 Îmbunătățește interfața sau temele vizuale
- 🌐 Ajută la traducerea aplicației în alte limbi
- 🐞 Raportează bug-uri sau propune funcționalități

## Pași

1. Forkează acest repository
2. Creează un branch nou: `git checkout -b feature/nume-funcționalitate`
3. Fă modificările și commit: `git commit -m "Adaugă funcționalitate"`
4. Trimite un Pull Request

## Ghid de stil

- Folosește ES6 modules
- Respectă structura modulară: `js/`, `data/`, `assets/`
- Comentează codul unde e relevant
- Testează local cu Live Server sau StackBlitz

Mulțumim pentru contribuție! 💙

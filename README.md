# 🌍 GeoDuel

**GeoDuel** este un joc educativ interactiv care combină geografie, întrebări tematice, explorare vizuală și sunet pentru o experiență captivantă. Este construit modular, extensibil și compatibil cu PWA (Progressive Web App).

---

## 🚀 Funcționalități

- 🗺️ Hartă interactivă cu Leaflet
- 🧠 Întrebări și quiz-uri geografice
- 👤 Gestionare profiluri (creare, import, salvare)
- 🎮 Moduri variate de joc: Standard, Explorare, Turistic, Enciclopedie, Quiz Rapid, Multiplayer
- 🏅 Realizări și statistici
- 🎨 Temă vizuală personalizabilă
- 🎧 Efecte sonore pentru acțiuni și realizări
- 📱 Compatibil cu mobil și instalabil ca aplicație (PWA)
- 🌍 Pregătit pentru localizare multilingvă
